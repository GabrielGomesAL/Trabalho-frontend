# Scrum do projeto

## Objetivo da sprint

Entregar uma aplicacao React executavel localmente com navegacao, formulario
validado, listagem dinamica, estado compartilhado, consumo de API REST e CSS
responsivo.

## Product Backlog

- Criar estrutura base do projeto React.
- Implementar navegacao com tres paginas.
- Criar formulario controlado com validacao.
- Compartilhar estado entre Cadastro e Listagem.
- Consumir e exibir dados de uma API REST.
- Renderizar listagem dinamica com dados locais e externos.
- Aplicar CSS externo e responsividade.
- Documentar execucao, rubrica e organizacao do trabalho.

## Sprint Backlog

As tarefas da sprint foram organizadas em issues no GitHub:

- Issue #1: Configurar base do projeto React.
- Issue #2: Implementar navegacao entre paginas.
- Issue #3: Criar formulario controlado com validacao.
- Issue #4: Implementar estado compartilhado entre paginas.
- Issue #5: Integrar API REST e normalizar dados.
- Issue #6: Criar listagem dinamica com filtros.
- Issue #7: Aplicar CSS externo e responsividade.
- Issue #8: Documentar projeto, rubrica e Kanban.
- Issue #9: Validar build e preparar entrega final.
- Issue #10: Sprint de desenvolvimento do trabalho frontend.

## Definition of Done

- A aplicacao roda localmente com `npm install` e `npm run dev`.
- O build de producao executa sem erro.
- As rotas Inicio, Cadastro e Listagem funcionam.
- O formulario valida os campos antes de cadastrar.
- Os dados cadastrados aparecem na listagem.
- Os dados da API REST aparecem na interface.
- A interface se adapta a telas menores.
- O repositorio possui commits progressivos e documentacao de entrega.

## Fluxo Kanban

- Backlog: requisitos levantados a partir da rubrica.
- Em desenvolvimento: implementacao por etapas e commits granulares.
- Revisao: build, auditoria e conferencia dos criterios.
- Concluido: funcionalidades implementadas e documentadas.

## Incremento entregue

O incremento final e uma aplicacao de gestao de clientes com:

- cadastro de clientes;
- validacao de campos;
- listagem com dados locais e contatos importados;
- filtros de busca;
- estado compartilhado entre paginas;
- consumo de API REST;
- interface responsiva;
- documentacao de entrega.
